# Lessons

Self-improvement loop. 사용자에게 교정받을 때마다 패턴을 기록하고, 같은 실수를 반복하지 않기 위한 자기 규칙을 적는다.

운용
- 항목 형식: `## YYYY-MM-DD — 한 줄 제목` → **무엇이 잘못됐나** → **자기 규칙 (Hard Rule)** → (있으면) **관련 변경**(어느 스킬/커맨드에 반영할지).
- 이 파일은 **입력**이다. `wannasong-skill-curator`가 미반영 교훈을 스킬 패치로 승격한다. 큐레이터는 이 파일을 쓰지 않는다.
- 자동메모리(`~/.claude/projects/.../memory/`)와 중복되거나 1개월 넘게 지난 항목은 `tasks/lessons-archive.md`로 옮긴다.
- 프로젝트 고유 교훈만 둔다. 지시 해석·태도 같은 일반 교훈은 자동메모리 `feedback_*`가 제자리다.
- afin·구 WannaSong 저장소에서 이미 스킬로 승격된 교훈(변경 출처 구분 보고, stale 메모리 주입 금지, 파이프 종료코드)은 `wannasong-harness-ops`·`/commit`·`/verify-runtime`에 반영돼 있어 여기 다시 적지 않는다.
